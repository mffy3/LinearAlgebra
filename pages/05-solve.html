WHY IT LOOKS LIKE THIS

一个方程组，两幅画

同一组数字，可以看成两条约束线，也可以看成两列的组合目标。两幅画说的是同一件事。

01

行视角：一条方程一条线

每个方程都是一条直线。两个方程就是两条线；解是它们同时满足的那个点。

a x + b y = b₁
c x + d y = b₂

两条线相交一次，就有一个解；平行，就无解；重合，就有无穷多解。

02

列视角：两列拼出 b

把矩阵看成两列 c₁、c₂。解 x = (x, y) 就是“用多少 c₁、多少 c₂ 才能拼出 b”。

x c₁ + y c₂ = b

b 落在两列张成的空间里，方程组才相容；落不进去，就无解。

03

三种结局，看两个秩

唯一解：det A ≠ 0，两列独立，b 有唯一表示。

无解：det A = 0，且 rank[A|b] > rank A；b 跑到列空间外面去了。

无穷多解：det A = 0，且 rank[A|b] = rank A；解是一条线，甚至整个平面。

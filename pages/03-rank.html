WHY IT LOOKS LIKE THIS

秩与零空间，一对搭档

同一张矩阵，从“留下了什么”和“压掉了什么”两个角度看，得到的维数正好加起来等于 2。

01

秩 = 列空间的维数

矩阵的两列张成列空间。两列不共线，秩是 2；共线，秩降到 1；全是零，秩是 0。

rank(A) = dim Col(A)

秩不是“非零元素的个数”，而是“输出空间还剩下几个独立方向”。

02

零空间 = 被压掉的方向

零空间收集所有满足 Ax = 0 的 x。它们没有被送到别处，而是被压到了原点。

Null(A) = { x : A x = 0 }

秩 1 时零空间是一条线；零矩阵时整个平面都是零空间；满秩时只有零向量。

03

rank + nullity = 2

二维空间一共只有两个独立方向。被保留的（秩）和被压掉的（零空间维数）加起来，必须正好是 2。

rank(A) + nullity(A) = 2

这条“秩—零化度定理”在 2×2 里最好看见：不是保留，就是压掉，没有第三种命运。

04

零空间一般不是列空间的垂线

这是一个常见误解。零空间垂直于行空间，不是垂直于列空间。

Null(A) ⟂ Row(A)

例：A = [[1,3],[2,6]]，Col 方向是 (1,2)，Null 方向是 (-3,1)，两者点积 = −1，并不垂直。

WHY IT LOOKS LIKE THIS

力，怎么写成一个矩阵方程

把“每根绳子出多少力”看成两个未知数，物理题就变成了线性代数题。

01

两列方向，两个未知数

两根绳子的方向是 u、v，张力是 T₁、T₂。它们的合力必须等于 −W：

T₁u + T₂v = −W

把 u、v 作为两列排成矩阵，未知数排成向量，这就是 Ax = b。

02

为什么正好是 2×2

水平方向一个方程，竖直方向一个方程；两个未知数，两个约束。

[u v] [T₁ T₂]ᵀ = −W

det[u v] = u × v。两列不共线，行列式不为 0，张力就唯一确定。

03

负张力是什么意思

数学会老实地给出负数；但绳子只能拉，不能推。负张力意味着这个几何下没有物理平衡。

T < 0 → 需要撑杆，
而不是绳子

张力为 0 则是“刚好松弛”：这根绳子不再出力，另一根独自承担全部重量。

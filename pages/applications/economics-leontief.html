WHY IT LOOKS LIKE THIS

为什么不是直接乘 A

因为 A 的产出里还有一部分要拿回去继续生产；逆矩阵把间接需求一轮一轮算完。

01

中间投入：A x

A 的列告诉你：每个行业每生产 1 元，需要农业和制造业各投入多少。

Ax = 中间投入

总产出 x 先要满足 Ax，剩下的才是最终需求 d。

02

Leontief 逆：直接 + 间接

把 x = Ax + d 移项，得到 (I − A)x = d；解出 x 就把所有轮次的需求都算进去了。

(I − A)⁻¹ = I + A + A² + …

只要 A 的谱半径小于 1，这个级数收敛，经济能产出正数。

03

为什么需要逆矩阵

如果只算 Ax + d，你会漏掉“为生产 Ax 所需要的投入”背后的投入。

x = (I − A)⁻¹ d

逆矩阵的列就是最终需求每增加 1 单位时，各行业总产出的增量。

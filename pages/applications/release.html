50 / 50 数学测试通过 · 13 个应用 · 0 Console 错误

01 · 数学

公式可复算

  • 所有 2×2 运算共用 `math.js`
  • 50 个数学单元测试 + 14 个接口测试通过
  • 应用页结果由同一套公式计算
  • 未使用伪造数据或外部 API

02 · 交互

能拖、能点、能复位

  • 十三个应用均有可操作控件
  • 应用检查选项都会给出反馈
  • 关键画布支持键盘方向键
  • 重置按钮恢复初始状态

03 · 可访问性

键盘与焦点

  • 全站原生按钮 / 链接 / 滑杆
  • 可见 `:focus-visible` 轮廓
  • 支持 `prefers-reduced-motion`
  • 页面均有 skip link 与唯一 h1

04 · 性能

拖动保持 60fps

  • 首屏资源 44.6KB（不含图片）
  • 矩阵变换拖动 60fps
  • p95 帧间隔 16.7ms
  • 1440×1100 · Edge headless 实测

KNOWN LIMITS

明确还没有做的事

  • 只做 2D 线性代数；没有 3D 旋转、四元数或 WebGL。
  • 音频页使用合成信号，不播放真实声音，也不上传音频。
  • Hamming(7,4) 只保证纠正单比特错误；多比特错误会显示异常状态，但不保证恢复。
  • Canvas 图形本身没有完整的数据表替代；读屏用户可通过旁边的数值和控件理解主要结论。
  • 没有后端、账号、云同步或数据库；所有内容在本地运行。
  • 不是 WCAG 认证；当前是人工键盘 / 焦点 / 对比度检查。
  • 性能数据来自本地 Edge headless；未覆盖低端手机或集成显卡设备。

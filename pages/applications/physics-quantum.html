WHY IT LOOKS LIKE THIS

概率从振幅里来

复向量不是“隐藏的 0/1”，它记录的是两种可能各自还有多少振幅。

01

叠加：两个基态都在

α 和 β 是复数。它们不是概率，而是概率的“平方根”振幅。

|ψ⟩ = α|0⟩ + β|1⟩

α = 1、β = 0 是 |0⟩；α = 0、β = 1 是 |1⟩。

02

Born 规则：概率 = |振幅|²

测量时，看到 0 或 1 的概率由两个振幅的模平方决定。

p(0) = |α|²，p(1) = |β|²

归一化保证 p(0) + p(1) = 1；这里用 θ 参数化，所以自动成立。

03

相位：不改概率，改干涉

β 的相对相位 φ 不改变 p(0)、p(1)，但会改变两个路径叠加后的干涉。

β = sinθ · eiφ

整体相位 eiγ 不可观测；只有相对相位有物理意义。
